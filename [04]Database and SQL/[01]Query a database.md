# **Query a database**

This reading reviews foundational SQL queries and introduces a key keyword for structuring query results. You will also explore the *Chinook* database, which serves as the dataset for readings and quizzes throughout this course.

**The Advantage of a Pre-Built Database:**

* **The Challenge of Building from Scratch:** Constructing a custom database is comparable to assembling a car rather than driving it. It requires defining manual rules for data storage, preventing data loss, and optimizing search speed.

**Our Approach:** Rather than spending weeks constructing a complex backend, we utilize the **Chinook database**. This allows you to immediately focus on querying data and extracting meaningful insights.

## **Basic SQL query**

There are two essential keywords in any SQL query: *SELECT* and *FROM*. You will use these keywords every time you want to query a SQL database. Using them together helps SQL identify what data you need from a database and the table you are returning it from.

The video demonstrated this SQL query:

*SELECT employee\_id, device\_id*

*FROM employees;*

Throughout the readings and quizzes, this course utilizes a sample dataset known as the *Chinook* database to execute queries. Representing data typically generated by a digital media business, this database contains eleven distinct tables—including *employees*, *customers*, and *invoices*—which store information such as customer names and billing addresses. Security analysts working for the company may need to query these records to analyze relevant organizational information.

&nbsp;

As an example, you can run this query to return data from the *customers* table of the *Chinook* database:&nbsp;

&nbsp;

SELECT customerid, city, country

FROM customers;
