# Google-Cybersecurity
4-Connect and Protect: Networks and Network Security
This module provides an overview of operating systems. 
Learners will explore the relationship between operating systems, hardware, and software, and they will become familiar with the primary functions of an OS. 
they will be able to recognize some of the most common operating systems in use today and also understand how the GUI and command line both allow users to interact with the operating system.
1.Describe the main functions of an operating system.
2.Recognize the most common operating systems in use.
3.Explain the relationship between operating systems, applications, and hardware.
4.Compare a graphical user interface to a command line interface.
